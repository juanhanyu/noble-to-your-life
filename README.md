# 书里 ShuLi · 这句话出自哪本书？

一个纯前端网页小工具：输入一句话，查明它是不是出自某本书、出自哪一章。

**把链接发给 QQ / 微信好友，对方点开就能用，无需注册、无需安装。**

## 快速开始

### 方式一：本地打开
直接用浏览器打开 `index.html` 即可（无任何构建步骤）。

### 方式二：部署到 GitHub Pages（推荐）
1. 在仓库设置 → Pages → Source 选择部署分支（如 `main` / `arena/e965176e-noble-to-your-life`），保存
2. 访问 `https://<用户名>.github.io/noble-to-your-life/`
3. 把这个链接发给好友即可

任何静态托管（Vercel / Netlify / Gitee Pages / 自己的服务器）都可以。

## 功能

- 🔍 **精确匹配**：原句命中，直接告诉你书名 + 章节 + 作者
- 🔎 **模糊匹配**：记错一两个字也能搜出来，并显示相似度百分比
- 📚 **内置书库**：论语、道德经、孟子、庄子、史记、诗经、楚辞、唐诗宋词、红楼梦、三国、鲁迅等 170+ 公有领域名句
- 📥 **导入整本书**：粘贴书籍全文，按句自动切分，「第X回/章」自动识别为章节
- 🧩 **导入 JSON 书库**、手动添加单句、导出、清空（数据保存在自己设备的浏览器里）
- ☁️ **云端书库**：链接后加 `?lib=书库JSON网址`，所有人打开同一链接即可查同一份书库
- 🔗 **结果分享**：查询后点 🔗 复制链接，好友打开直接看到这条结果
- 🎲 随机名句、手机端优先的深色界面

## 书库格式（JSON）

```json
[
  { "t": "句子原文", "b": "书名", "c": "章节（可选）", "a": "作者（可选）", "note": "备注（可选）" }
]
```

把这段 JSON 传到 GitHub 仓库（用 raw 链接）或任意支持跨域的静态地址，然后把网址拼到
`你的网址?lib=JSON的raw网址` 后面发给朋友即可。

例如：
```
https://juanhanyu.github.io/noble-to-your-life/?lib=https://raw.githubusercontent.com/用户名/仓库/主分支/quotes.json
```

## 使用建议

- 想查某一本特定书：在自己的设备上「导入整本书文本」，然后在书里搜索
- 想让所有朋友都能查同一本书：把该书做成 JSON 上传，用 `?lib=` 参数分享链接
- 微信内打开未知链接可能提示「继续访问」，属正常现象；绑定自己的域名可避免

## 方案对比

| 方案 | 难度 | 说明 |
|---|---|---|
| **网页链接（本项目）** | ⭐ 最简单 | 发链接即可用，QQ/微信都支持 |
| 微信小程序 | ⭐⭐⭐⭐ | 需注册账号、个人主体审核，体验更原生 |
| QQ 机器人 | ⭐⭐⭐ | 需服务器 + Lagrange/NapCat 等框架，好友在群里@机器人查询 |
